> Convert any text content using one or multiple regex

## Stack

- [React 19](https://react.dev) — reactive UI with live preview as you type
- [TypeScript](https://www.typescriptlang.org) — fully typed codebase
- [Vite](https://vitejs.dev) — fast dev server and build tool
- [Tailwind CSS v4](https://tailwindcss.com) — utility-first styling
- [Framer Motion](https://motion.dev) — typewriter heading animation
- [Vitest](https://vitest.dev) — unit tests with v8 coverage
- [oxlint](https://oxc.rs/docs/guide/usage/linter) — fast linting
- [Turbo](https://turbo.build) — build pipeline orchestration
- [pnpm](https://pnpm.io) — package management

## Usage

```bash
pnpm dev        # start dev server
pnpm build      # type-check + build
pnpm check      # lint, build, test
pnpm test       # run unit tests
```
